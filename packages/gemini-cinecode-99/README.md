# @gemini-agy/cinecode-99

Responsive container and 99 procedural code-driven film animations for Remotion.

## Responsive Canvas Usage
```tsx
import { ResponsiveCineCanvas } from '@gemini-agy/cinecode-99';

export const MyAdaptiveVideo = () => (
  <ResponsiveCineCanvas aspectRatio="9:16">
    {/* Your Video Content */}
  </ResponsiveCineCanvas>
);
```
Supported aspect ratios: `9:16`, `16:9`, `1:1`, `4:5`.
