# Gemini Video Director: Viral Social Video Generation Blueprint

This blueprint condenses high-performing viral video architectures from GitHub topic scrapes (`opus-5-5`, `free-video-generator`) into deterministic generation instructions for **Gemini 3.8 Flash High**.

## 1. Pacing & Pattern Interrupts
1. **The 3-Second Hook**: The user's screen must change state within the first 90 frames (at 30 fps).
2. **Beat-Syncing**: Always snap scene cuts to the beatmap output generated by `analyze_media.py`.
3. **Safe Zones**: Ensure text captions do not enter the right 18% or bottom 22% of the canvas when rendering 9:16 vertical videos.

## 2. Monetization & Audio Loudness
- Standardize all background music and voiceover tracks to **-14 LUFS** using FFmpeg `loudnorm`.
- Audio clipping above `-1.0 dBFS` triggers automatic monetization demonetization flags on YouTube and TikTok.

## 3. High-Throughput Remotion Rendering Command
```bash
npx remotion render src/index.ts <CompositionID> out/video.mp4 \
  --concurrency=2 \
  --gl=angle \
  --ffmpeg-override='-c:v libx264 -pix_fmt yuv420p -preset fast'
```
