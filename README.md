# Gemini Antigravity Video Studio

Autonomous AI Video Editor & 3D Viral Video Studio optimized for **Google Antigravity** and **Gemini 3.8 Flash High**.

## Overview
This monorepo unifies procedural film animation, 3D physics rendering, particle effects, audio beat detection, and social media safe-zone overlays into an integrated Remotion pipeline.

## Modules
- `packages/agy-gemini-harness`: Multi-agent orchestration runner.
- `packages/gemini-cinecode-99`: Procedural film animations with responsive aspect ratio containers (9:16, 16:9, 1:1, 4:5).
- `packages/gemini-shotcraft-studio`: Remotion shot recipes, workbench editor, and social media safe-zone overlays.
- `packages/gemini-pixelfx-vfx`: Procedural 2D particle and shader effects for Remotion.
- `packages/gemini-3d-physics-stage`: Deterministic 3D rigid-body physics and post-processing scene.
- `packages/gemini-blender-mcp-bridge`: Blender MCP bridge for headless 3D asset generation.
- `packages/gemini-audio-beatlock`: Audio beat, onset, and vocal pause detection engine.
- `packages/gemini-viral-blueprints`: Social media retention guides and monetization compliance rules.
